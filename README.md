# DC Master

## DCMaster：从画布到交付，一次完成

面向 UI 设计师和设计交付场景的 Figma 插件。

- **批量导入，省去整理图层**：拖入图片或整个文件夹，递归读取子目录；保持原始像素尺寸与名称，去掉格式后缀，可选择每图新建 Frame。
- **多格式、多倍率，一次交付**：选中多个对象，一次生成 PNG、JPEG、WebP、SVG、PDF；支持常用及自定义倍率，自动按格式和倍率打包 ZIP。
- **先看效果，再决定压缩**：四档压缩提供体积与节省比例，每个输出文件都有效果预览。
- **多对象直接生成 GIF**：选区作为动画帧，可设置每帧时长，预览实际生成的循环动图。
- **本地处理，无需上传素材**：编码器内嵌，不依赖在线压缩服务；紧凑界面和独立导入弹窗。

适合：图标整理、切图交付、多倍率资源导出、界面状态动图。

## DCMaster 使用与技术说明

本地运行的 Figma Design 图片导入与导出插件。已包含构建产物，无需安装 Node.js 即可导入使用。

## 安装与使用

1. 在 Figma 桌面端打开设计文件，进入 **Plugins → Development → Import plugin from manifest…**。
2. 选择本目录的 `manifest.json`。请保留相邻的 `dist` 文件夹，不要只移动 manifest。
3. 在画布选择一个或多个对象，运行 **DC Master**。
4. 勾选格式及倍率，选择压缩档位，按需设置特殊选项和文件命名。
5. 点击 **预览**，试压完成后点击 **保存**。

默认倍率为 1 / 1.5 / 2 / 3 / 4，支持输入多个自定义倍率（逗号或空格分隔，范围大于 0、不超过 16）。

## 图片导入

运行插件，点击 **选择图片并导入画布**，可多选 PNG / JPG / WebP（单批最多 128 MB）。无需预先选择画布对象。可将文件夹直接拖入插件窗口，递归导入子文件夹图片并跳过其他文件；也可点击“选择文件夹”。

- 每图创建一个独立 Frame，内含一个图片矩形，两者名称均为原文件名（去掉格式后缀），不附加编号。
- Frame 和图片矩形采用 Figma 解码后的原始像素宽高，不主动缩放或重新编码，透明图片不添加白底。
- 在当前视口附近自动换行排列，间隔 40 px；完成后选中新 Frame 并定位视口。
- 整批成功后可撤销；任一图片无法读取时清理本批已创建的 Frame，修复后重试。
- 不支持 SVG、GIF 或视频导入；超过 Figma 自身图片尺寸/解码限制时会提示失败。

## 输出规则

- 默认每个选中对象独立输出；PDF 可勾选合并并选择页面顺序。
- 路径：`格式/倍率/文件名.格式`，例如 `png/2x/首页@2x.png`。
- 1x 不添加后缀；其他倍率添加 `@1.5x`、`@2x` 等。
- 默认使用选中对象自身名称，不使用其父 Frame 名称。关闭后使用 `png_001.png` 等；同一对象在各倍率下序号保持一致。
- 清理文件名非法字符；同名文件自动加序号，避免覆盖。
- SVG 改变输出宽高并保留 viewBox；PDF 缩放页面及内容，保留原始矢量。倍率不增加已有嵌入位图的真实细节。

## 压缩与预览

所有编码器及 WASM 内嵌，无 CDN、无上传、无服务器。压缩在 Web Worker 中执行，支持取消。

- PNG：OxiPNG。无损档禁用透明像素 RGB 改写，解码后逐像素校验；高清/均衡/极小使用 UPNG 调色板量化后再用 OxiPNG 优化，并校验黑白背景合成后的最大误差与均方根误差。深度模式比较多个优化等级，保存更小结果。
- WebP：libwebp。严格无损开启 `lossless`、`exact`，并校验完整 RGBA 一致。其他模式按颜色数量、边缘复杂程度、透明度等信息选参。深度模式试压多个编码方案。
- JPEG：MozJPEG。先从 PNG 源图合成指定背景，再编码。严格模式使用 Q100、4:4:4，**仍然属于有损首次编码**，不会伪称无损 JPEG。高保真及体积优先按特征调整质量及色度采样。
- SVG：SVGO 保守清理注释、元数据和空属性，不降低路径精度。
- PDF：pdf-lib 对象流优化，不下采样图片、不栅格化页面。本版未集成 qpdf 深层数据流重压缩，不能保证明显减小体积。

预览使用实际试压结果，不套用固定压缩率；下载复用已压缩数据。节省比例 = `1 - 输出大小 / 基准大小`。PNG、SVG、PDF 对比同倍率未优化版本；WebP 对比 PNG 源图；JPEG 对比 Q100、4:4:4 的基准 JPEG。跨格式汇总仅用于显示本次各自基准总量的变化，不是统一画质的编码器排名。ZIP 包含目录与文件头，大小可能略有差异。

PNG / SVG / PDF 无有效收益时保留未优化版本。图片特征分类为启发式方法，尚未接入感知质量指标搜索。PNG 深度压缩本版使用 OxiPNG，未集成 Zopfli。压缩程度对 SVG / PDF 没有额外激进处理。

## 边界

- 默认导出为 sRGB；严格无损指相对于 Figma 导出的 sRGB 位图像素，不代表保留原始设计文档的 Display P3 色域。
- 单个输出位图限制为 3200 万像素、最长边 16384；累计输出超过 256 MB 时提示分批处理。
- 修改设置、选区或当前页面内容后需要重新预览。
- 本地 Chrome 编码器测试不等同于 Figma 宿主测试；复杂蒙版、混合模式、字体等仍需在实际设计文件中验收，导出表现受 Figma 原生渲染影响。

## 本地开发插件同步

可在项目根目录创建未入库的 `.local-deploy.json`，内容为 `{ "target": "已在 Figma 中导入的插件目录" }`。每次 `npm run build` 成功后自动更新目标目录的 manifest 和构建文件，保持插件 ID 与注册路径。重新运行插件即可加载更新；正在打开的插件需关闭后重开。

## 记住上次设置

选项修改后自动保存在本机，重新打开时恢复上次的勾选项及输出设置；不恢复任务队列或自动开始处理。

### v1.1.0 MP4 导出

格式中增加 MP4。选择视频/动画图层或 Frame，插件定位所属顶层 Frame，相同 Frame 只导出一次。视频保存在 `mp4/倍率/名称.mp4`，非 1x 添加倍率后缀。特殊选项中可设置 12/24/30/60 fps。压缩档位无损/高清映射到 Figma HIGH，均衡为 MEDIUM，极小为 LOW；视频没有无损保证，深度优化不作用于视频。

使用 Figma 原生 `exportAsync({format:'MP4'})`，导出完整动态顶层 Frame，不是提取 VideoPaint 原始文件。普通视频填充是否构成可导出的动态内容由 Figma 判断，静态 Frame 或不支持该接口的宿主会报错。没有所属 Frame 时应先在 Figma 中将视频放入顶层 Frame。自定义倍率通过目标宽度请求；最大 3840×2160，超出后 Figma 保持比例缩小。文件名倍率表示请求倍率。插件不承诺音频或超出 Figma 原生接口的时间线能力。

MP4 显示实际文件大小，不虚构节省比例，也不加入图片压缩率统计。编码中的取消会丢弃结果，但 Figma 正在运行的原生编码不能中断。已通过队列模拟和界面回归，尚未完成真实 Figma 动态文档内的 MP4 编码验收。

参考：https://developers.figma.com/docs/plugins/api/properties/nodes-exportasync/

### v1.0.3 PNG 减色与实际样本

新增 UPNG 减色 → OxiPNG 重压缩 → 黑白背景合成误差校验 → 选择最小合格文件。无损档增加精确调色板重编码候选，仍须 RGBA 完全一致。非无损档允许改变透明像素 RGB 和半透明颜色/透明度，但不改变输出宽高。

| 档位 | 调色板搜索（最多颜色数） | 合成 RMS / 最大通道误差上限（0–255） |
| --- | --- | --- |
| 高清 | 256、128、64、32、16 | 0.8 / 5 |
| 均衡 | 上述加 8 | 2 / 14 |
| 极小 | 上述加 8、4 | 5 / 36 |

每档均保留无损候选；只选更小且误差合格的结果，因此不保证四档大小严格不同。误差指标是数值保护措施，不等于感知质量保证。照片、渐变、大图可能更适合 WebP/JPEG，减色在大图上耗时较长，可取消。

用户提供的第一张 149×143 PNG：1128 B → 无损 574 B / 高清 574 B / 均衡 550 B / 极小 447 B（深度优化）。最小的附图为 495 B，447 B 相比它小约 9.7%，但没有相同画质的 TinyPNG 对照实验，不能据此声称编码器全面优于 TinyPNG。具体结果及误差记录见 `tests/sample-results/results.json`。

复验：`node tests/samples.mjs`。所有图片仅本地处理。UPNG 项目：https://github.com/photopea/UPNG.js 。
